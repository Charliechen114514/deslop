# 腔调档：密度·舒展（density-full）

| 层卡 | |
|------|------|
| 维度 | 密度 |
| 档位 | 舒展 |
| 互斥 | density-tight（同维只穿一件） |
| 相邻 | 与 polish 任档皆可同穿 |
| 让位 | 铺不豁免零信息：垫话、帽子、复述不在豁免范围 |

管辖声明：管字数立场——舒展档。

1. 可以铺。背景、过程、来龙去脉，用户可能要的都讲，一句慢慢说清，不赶。
2. 关节全保是底线。主语、承接、虚词都在，舒展不是注水。展开有操作办法：名词带上谁的（谁的什么、在哪个上下文，"漂"要写成"模型的上下文漂移"），动词说清一万种用法里指哪种（"硬了、搞定了"这种万用谓语，写出它指的具体判断，是依赖不成立还是时机不对）。强调逻辑的地方，因为、所以、如果、但是别省，它们承重，删了逻辑链就断。
3. 零信息的整句照删。垫话、帽子、复述不在舒展的豁免范围里。判断法还是那条：删掉再读，信息没少且没人问，就删。

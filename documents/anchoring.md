# 机制：重锚（长对话防漂移，Claude Code 专用）

配方写进 style.md，只解决"规则存在"。你在长对话里能看到模型漂：开头几轮照配方说，越往后越走样。最危险的是宿主做上下文压缩（context compaction）的那一刻，因为压缩把整段对话连同开头注入的配方全文一起换成一份摘要，摘要之后的回复就没有配方管着了。

重锚的思路：把配方在对话过程中反复送回模型眼前。什么时候送、送多重，由策略文件 build/policy.json 定，不由对话内容定，你想调节奏只改它。

## 三件钩子

- **reanchor.py**（UserPromptSubmit，每条用户消息跑一次）：按 policy.json 的 tiers 决定这一轮注入什么。轻的时候只注入一行提醒。重的时候注入全量锚，四个部件：score（自评指令，附一个本轮暗语，暗语是个普通词，模型要把它织进回复任意一句）、voice（定声提醒，开口先对上用户语气）、routing（style.md 的路由头）、read（强迫模型用 Read 现场读 build/style.md 全文再回答）。现场读的永远是磁盘上的最新正本，零截断零摘要，你改完 combo.json 重跑 bake，下一个锚读到的就是新内容。
- **kick.py**（PostCompact）：压缩刚结束就落一个旗标文件，下一条消息必定触发全量锚，不管当时轮到没轮到。
- **gate.py**（Stop，拦截器）：回合收尾时体检最终输出，查三类：判死词命中（error 级的词表命中）、机械计数超限（破折号限额，压缩碎片是留给层里 lint 块的计数位，当前组合没有会产生它的规则）、全量锚注入后的那个回合没把本轮暗语织进回复。任何一类命中就把回复打回重写。拦截器只在这类回合核对暗语。每轮的拦截次数有上限（默认一次，policy 的 gate.max_block），拦截器自身故障一律放行，体检脚本不能把你的会话卡死。

已知边界：拦截器认这类回合只看拍数（beat 条件），不看体格阈值（min_size）。对话记录体格还没到 150000 字节时，轮到拍数的那个回合实际注入的是不带暗语的轻提醒，回复里自然没有暗语，可能被误拦一次（每轮拦截上限一次，到上限就放行）。

## 默认四档与 policy.json

tools/init.py 在安装时把 example/ 抄成 build/，抄来的 policy.json 里你默认拿到四档（tiers 按排列顺序匹配，先中的先得）：

| 档     | 触发                                                             | 动作         |
|--------|------------------------------------------------------------------|--------------|
| 重锤   | 压缩后下一轮（force）                                            | 全量锚       |
| 开场绳 | 会话第一轮（first_turn）                                         | 全量锚       |
| 中绳   | 对话记录体格达到 min_size（默认 150000 字节）后，每 3 条用户消息一次（beat:3） | 全量锚 |
| 常绳   | 其余每一轮（every_turn）                                         | 一行轻提醒   |

策略的全部字段都在 policy.json 里，你动它就行，钩子代码一个字不用碰：

- tiers：定有哪些档、各自什么时候触发。when 的条件词五种：every_turn、beat:N、min_size:S、first_turn、force。
- action 两种：say 加文本键（注入 texts 里对应的一句），或 anchor 加部件列表。
- texts：覆盖每句注入文案，不覆盖的用默认。
- score：自评部件的总开关。
- gate 开关组：enabled（拦截器的总开关）、banned_words（查不查判死词，要连判死词一起关，得把 fragments 也关掉）、score_nonce（核不核对本轮暗语）、fragments（查不查机械计数）、max_block（每轮最多拦几次，默认 1）。

你想改中绳每几条来一次（beat 的数字）、想换每句注入的措辞（texts）、想干脆去掉某一档（tiers 里删一条），都只改 policy.json。会话计数按 session 各自记在 build/.reanchor-count，你开几个会话并行，也不会互相踩。

## 装法

你照 [INSTALL.md](../INSTALL.md) "机制重锚"一节的接法，把三个钩子挂进 settings.json。

## 边界

钩子是 Claude Code 的机制，配方正文不带它，配方正文工具中立，任何宿主能用。你换了宿主还想要等效强度，得自己找事件入口，思路是通用的：轻提醒每轮常在，重锚按拍来，压缩后立刻补一次。

# 预设组合表

组合 = 挑好的层写进 build/style.md（写法见 [example/](example/)，build/ 已 gitignore）。懒得挑，直接抄一组。

挑法一句话：base（说清楚的宪法）必装，病灶（AI 味、翻译腔这类）挑着装，腔调八维各选一份档位，场景按活挑，个人层（判死词表、语气校准）按你是谁写，人格卡（狐娘这类）按口味另挂（写法见 [example/](../example/)）。

| 组合     | 适合谁                                     | 层                                                                                                                                                                                      |
| -------- | ------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 松弛对话 | 日常搭档，要清楚、要没人味、要松弛不机关枪 | clarity + anti-ai + natural-chinese + rhythm-mixed + particles-follow + address-follow + emotion-light + slang-follow + density-full + rhetoric-plain + polish-raw + 个人层 + artifacts |
| 工程默认 | 快节奏，信息密度优先                       | clarity + anti-ai + rhythm-tight + particles-off + address-off + emotion-off + density-tight + rhetoric-plain + polish-finished + artifacts                                             |
| 极简     | 只求说清楚                                 | clarity                                                                                                                                                                                 |
| 代写专用 | 常替人写邮件、帖子                         | clarity + voice-calibration + anti-ai + density-full（按底样定）                                                                                                                        |
